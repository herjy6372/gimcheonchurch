# 김천침례교회 (GIMCHEON BAPTIST CHURCH)

기독교 한국침례회 김천침례교회 공식 웹사이트.

## 구성
- `index.html` — 메인 (예배안내 · 오시는 길 지도)
- `intro.html` — 소개
- `history.html` — 연혁
- `album.html` — 앨범
- `app-beta.html` — 성경&찬양 앱 Android 비공개 테스트 신청 (메인 배너에서 새 창으로 열림, 신청 내용은 관리자 페이지에서 확인 후 참여 안내 문자 발송)
- `style.css` / `script.js` — 공통 디자인·스크립트

## 보기
`index.html` 을 웹 브라우저에서 열면 됩니다.
